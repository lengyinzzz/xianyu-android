# 闲鱼自动回复 · Android 客户端

本项目是**纯前端（客户端）**，用于连接已部署好的闲鱼自动回复**后端服务**。

不需要改后端代码，也不需要单独再搭一套服务。只要后端已经在跑，手机上安装本 App，填入服务器地址即可使用。

---

## 说明

- 本 App = 前端控制端（Android）
- 你已有的后端服务（如 `http://IP:8089`）= 服务器
- 二者通过 HTTP API 通信，登录后即可在手机上操作

---

## 功能

| 模块 | 说明 |
|------|------|
| 登录 | 填写服务器地址与账号密码；支持滑动验证 |
| 控制台 | 资金/订单统计、服务状态、重启、账号概览、订单补评价 |
| 在线聊天 | 连接账号、会话列表、收发消息 |
| 商品管理 | 商品列表与搜索 |
| 卡券管理 | 卡券列表与搜索 |
| 订单管理 | 订单列表与搜索 |
| 风控日志 | 风控记录查看 |

---

## 使用方法

1. 确认后端服务已启动并可访问（例如 `http://192.168.1.100:8089`）
2. 安装本 App
3. 打开后输入**服务器地址**（与网页后台同一后端地址即可）
4. 使用后台账号密码登录
5. 通过底部导航使用各功能

无需在后端做额外配置或改代码；能打开网页管理后台的同一套服务，本客户端一般也可直接连。

---

## 构建 APK（GitHub Actions）

1. 将本仓库推送到 GitHub  
2. 打开 **Actions** → **Build APK** → **Run workflow**  
3. 构建完成后在 **Artifacts** 下载 APK 安装  

也可用 Android Studio 打开本项目本地编译。

---

## 注意事项

1. 手机需能访问你的后端地址（同一局域网或已映射到公网）。  
2. 使用 `http` 内网地址时，请保证网络畅通。  
3. 若后台开启了登录滑动验证，登录页需先完成验证。  
4. 部分复杂管理（如卡券新建、商品绑卡等）仍以网页后台为主，本客户端侧重常用查看与操作。

---

## 项目定位

| 角色 | 是什么 |
|------|--------|
| 本仓库 | Android 前端客户端 |
| 原闲鱼自动回复系统 | 后端 + 网页前端（需已部署） |

本客户端**不替代后端**，只作为手机端入口使用已有服务器。
